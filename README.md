# Bàn vẽ hình động

Trang hướng dẫn học sinh lớp 9 dựng hình bằng GeoGebra (bấm chuột hoặc gõ lệnh) và The Geometer's Sketchpad, đi kèm sách *Tư duy hình học 9*.

Bốn bài dựng từng bước, có bàn vẽ kéo điểm và số đo trực tiếp:

- Bài 1.1 – Trưng Vương: dựng đúng, kéo và kiểm tra AI ⊥ CK
- Bài 2.6 – Mỹ Đình 2: khái quát bằng thanh trượt
- Bài 3.3 → 3.7 – Cầu Diễn → Đại Áng: nhìn tương tự khi đổi vai B, C
- Bài 4.6 – Đức Giang: bật vết và quỹ tích

Trang tĩnh một tệp (`index.html`), không cần build. Mỗi lần đẩy lên nhánh `main`, Vercel tự triển khai lại.
